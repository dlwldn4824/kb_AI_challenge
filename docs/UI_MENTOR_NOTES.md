## 2. 디자인 지시 15 (삭제 우선)

### 삭제

**[1] 화면1의 카드 6장을 흰 시트 1장으로 합친다.** KPI Card 5개 + 테이블 Card → 하나의 `rounded-[8px] border border-line bg-card` 섹션. KPI는 `grid-cols-[1fr_1fr_1fr_1fr_366px]`, 셀 사이 `border-l border-line-soft`, 스트립 높이 84px(`px-[22px] py-[16px]`), 아래 `border-t border-line`. `개입 필요` 셀 좌측 4px 옐로 바만 남김. Figma 정본 그대로.

**[2] `shadow-card` 전면 삭제.** `ui.tsx:27` → `border border-line`만. 말풍선 shadow 제거(→`border border-line-soft`). 그림자는 떠 있는 것 2개만: Toast(`shadow-raised`), 폰 목업(`0 2px 12px rgba(38,40,44,.10)`).

**[3] 상태 배지를 텍스트로 되돌린다.** 알약 제거 → `text-[13px]`. `검토 대기` text-ink / `검토 중` text-ink-soft + ● 6px bg-kb-star / `검토 완료`·`표본 검토` text-faint / **`차단`만 알약 유지**(bg-danger-bg text-danger). tier-C 하늘색은 상태에서 완전 제거.

**[4] 중복 문구 4개 삭제.** ① done "불일치 시 발송 차단" 카드 통째 삭제 ② review "미판정이 남아 있으면…" 삭제(CTA 아래 구체 문구만) ③ 신호 분해 행 SIGNAL_NOTE 삭제 → `[칩] ×점수 · 유형명 · N번 구절 · 근거 "…"` ④ done 오늘 발행 결과에서 발행/사람 개입/무작위 표본 3칸 삭제, `발송 차단 1`만 봉인 정보 카드 하단 한 줄로 흡수.

**[5] dashed 빈 상태 박스 2개 제거.** 한 줄 텍스트(`text-[13px] text-muted`)만 같은 높이로(min-h 40/56px). 문구: "수정하면 여기에 대조됩니다." / "수정한 구절에만 적용됩니다."

**[6] 장식 글리프 제거.** ①② 원문자, 선택 사유 ✓, DESIGN_POLISH의 "별 심볼 워터마크 허용" 조항.

### 조정

**[7] 옐로 예산: 화면당 채도 옐로(#FFCC00) 객체 1개.**
| 역할 | 허용 색 | 화면당 |
|---|---|---|
| 1차 행동(CTA) | #FFCC00 풀필 + text-ink | 1개 |
| 강조 바 | #FFCC00 3~4px | ≤2개 |
| 선택 tint | #FFFBEA | ≤2영역 |
| 티어 A 칩 | #FEEFC5 (정본 불변) | 제한 없음 |
| 상태·hover·포커스·배지·테두리 | **옐로 금지** | 0 |

즉시: 선택 사유 버튼 `bg-ink text-white border-ink`(Figma 정본), hover는 `hover:bg-paper`, 큐 행 hover도 `hover:bg-paper`, SYNTHETIC 배지 `border-line bg-card text-muted` 중립화. 폰 목업 내부는 별도 예산. 비옐로 채도 면적 화면당 6% 이하, 옐로 풀필 2% 이하.

**[8] 한글 줄바꿈.** `globals.css`: `.ko { word-break: keep-all; overflow-wrap: break-word; }` — 구절/diff/발송 문안/문장 대조/말풍선/신호 설명/상품·문의 요지 셀에 적용. mono 값에는 적용 금지.

**[9] 한글 font-mono 제거.** chrome meta는 등기번호·시각·R에만 mono, SealField·LookupRow·R 산식 한글부는 산세리프 + `.tabular`(tabular-nums). mono 허용 목록: 등기번호 / sha256·HMAC / HH:MM(:SS) / `R n` / `×점수` / `dispatch_blocked #35`.

**[10] `leading-none` 한글 금지.** 라벨 `leading-[1.35]`, 값 `leading-[1.4]`, KPI 숫자(34px)만 `leading-[1.05]`.

## 3. 모션 절제 가이드

전제: ① 제출물의 실체는 정지 스크린샷 — 진입 애니메이션은 중간 프레임 캡처 위험만 만든다. ② 은행 콘솔에서 모션은 상태 변화 알림이지 연출이 아니다.

**빼기**: KPI count-up(수치가 틀려 보이는 프레임 위험), 테이블 행 stagger(R 정렬 의미가 "로딩 순서"로 오독), 패널 가로 slide-in(translateX는 위치 변화 의미), hover transform/scale.

**남기기**: panel-in(opacity+translateY(-4px), 0.16s ease-out), toast-in(0.18s), transition-colors 120ms 통일(판정 토글은 100ms 가능), 승인→발송 Spinner.

**추가 1개만**: 화면3 일치 판정 바 — opacity 0→1 + translateY(4px), 0.22s, delay 200ms. 그 외 어디에도 delay 금지.

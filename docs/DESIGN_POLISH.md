## 2. 브랜드 토큰 (CSS 변수로 정의)

```css
--kb-yellow: #FFCC00;        /* 공식 앱 아이콘 샘플링. 주 포인트/CTA */
--kb-yellow-dark: #F5B800;   /* hover */
--kb-star: #FCAF16;          /* 로고 별 심볼 (로고 SVG fill 그대로) */
--kb-gray: #776C61;          /* 로고 워드마크 웜그레이. 보조 텍스트/라벨 */
--kb-ink: #26282C;           /* 본문 텍스트 (스타뱅킹 실측 근사) */
--kb-bg: #F5F6F4;            /* 화면 배경 (스타뱅킹 실측) */
--kb-card: #FFFFFF;
--tier-s-bg: #FBDAD5; --tier-s-fg: #C0392B;   /* pdf-ref-10 근사 — PNG에서 재샘플 후 보정 */
--tier-a-bg: #FDEEC8; --tier-a-fg: #B07D00;
--tier-b-bg: #DDEFD8; --tier-b-fg: #3E7A33;
--chat-bg: #F6F0E7;          /* 상담 채팅 배경 (pdf-ref-08에서 재샘플) */
--chat-header: #4A4237;      /* 상담 헤더 다크브라운 (재샘플) */
--danger: #D93025;           /* 409 배너/차단 */
--ok: #1E8E3E;               /* 일치/적합 */
```
정확한 값은 반드시 각 PNG에서 magick 등으로 재샘플해 보정할 것(위 값은 근사 시작점).

**옐로 사용 규약 (v1.1)**: 채도 옐로(#FFCC00) 풀필은 화면당 CTA 1개(면적 2% 이하). 강조 바(3~4px) ≤2개, 선택 tint(#FFFBEA) ≤2영역. **상태·hover·포커스·배지·테두리에 옐로 금지.** 티어 칩 3색은 pdf-ref-10 정본으로 불변 — 충돌 시 브랜드 옐로가 양보한다. `--tier-c`(블루)는 티어 C 전용, 상태 등 다른 의미로 재사용 금지. 폰 목업 내부는 별도 예산(고객 앱 인용).

## 3. 타이포그래피

- KB금융 전용서체(KB금융 제목체/본문체)는 공식 다운로드 링크가 없어 번들 불가 → **Pretendard**를 npm(`pretendard`)으로 설치해 로컬 번들(외부 CDN 금지). `font-family: 'Pretendard Variable', Pretendard, ...`.
- 위계: UI_MENTOR_NOTES §2 [11]의 6단 스케일을 따른다(본문 14/1.7, 밀집 13/1.6, 캡션 12/1.5, KPI 34/1.05 tabular).
- **한국어 조판 (v1.1)**: ① 본문에 `word-break: keep-all; overflow-wrap: break-word;` 필수(mono 값 제외). ② **한글에 monospace 금지** — mono 허용 목록: 등기번호/sha256·HMAC/HH:MM/`R n`/`×점수`. 자릿수 정렬은 `tabular-nums`로. ③ 한글에 `line-height: 1` 금지(본문 1.7·밀집 1.6 두 값만). ④ 본문 하한 14px(폰 목업 내부만 예외).

## 4. 화면별 적용 지침

### 공통 크롬
- 좌측: KB 로고(svg, 높이 ~20px) + 세로 구분선 + `답변등기 · <화면명>` — 스타뱅킹처럼 화이트 헤더 + 하단 1px 보더, 상단에 3px KB 옐로 액센트 라인.
- 우측: 날짜/`상담원 EMP-4471` + **SYNTHETIC DEMO · 합성 예시 데이터** 배지(옐로 배경 or 아웃라인, 항상 노출).
- 배경 `--kb-bg`, 콘텐츠는 화이트 카드(라운드 12~16px, 얕은 그림자 `0 1px 3px rgba(0,0,0,.06)`).

### 화면 1 (발행 대기)
- KPI 4개: **카드로 쪼개지 않는다.** 테이블과 같은 흰 시트 위에 세로 헤어라인으로만 구획한다(Figma 정본). `개입 필요` 셀 좌측 4px 옐로 바만 강조, R 산식 셀은 연옐로 배경. 스타뱅킹은 **컬러·CTA 톤**의 레퍼런스일 뿐 **면 구조**의 레퍼런스가 아니다(대고객 앱 카드 관용구를 콘솔에 옮기지 말 것).
- 큐 테이블: 티어 칩 = pdf-ref-10 칩 스타일(파스텔 배경+진한 글자, 라운드 4~6px). 1위 행 좌측 4px KB 옐로 강조 바 + 연옐로 hover. 상태 배지(검토 대기/중/완료/표본 검토) 톤 구분.
- 신호 분해 패널: 슬라이드-인 카드, 유형·티어·점수·근거 구절 인용.

### 화면 2 (검토)
- 유지/수정 토글: 선택 시 유지=그레이 필, 수정=옐로 필. 신호 하이라이트 = 티어 색 파스텔 마킹.
- 사유 원탭 6버튼: 선택 시 **ink 다크 필(`bg-ink` + 흰 텍스트), 체크 글리프 없음**(Figma 정본 — 옐로 풀필은 화면당 CTA 1개뿐). 적합 카드 좌측 그린 바/✓, 불일치 카드 레드 바/!.
- `승인하고 발송` = KB 옐로 CTA(스타뱅킹 "이체" 버튼 스타일, ink 텍스트), disabled 시 회색+사유 툴팁. `보류` = 아웃라인.

### 화면 3 (발행 완료)
- 해시 박스: monospace, `앞6…뒤5`, 일치 카드 그린 ✓.
- **고객 수신 화면 목업은 pdf-ref-08을 그대로 재현**: 폰 프레임(라운드 ~40px, 상단 상태바 12:54), 다크브라운 헤더 `종료된 상담`, 베이지 배경, 우측 옐로 사용자 말풍선, 좌측 화이트 상담원 말풍선(별 심볼 아바타 + "KB국민은행 상담원" + 시각), 등기 카드는 화이트+옐로 `등기` 배지, 하단 풀폭 옐로 CTA `챗봇 상담하기`. 앱 아이콘 활용 가능.
- 등기 조회 패널: 라벨(--kb-gray 12px) + 값(15px) 그리드.
- **레드는 실제로 발생한 사건에만 쓴다 (v1.1)**: 정책·규칙 설명을 레드 면으로 상시 노출하지 않는다. 같은 사실을 한 화면에서 두 번 이상 말하지 않는다.

### 409 차단 배너
- 풀폭 `--danger` 배경 화이트 텍스트, `409 DISPATCH BLOCKED` + 기대/실제 digest monospace 대조, 아래 dispatch_blocked 이벤트 카드.

## 5. UX 마감 체크리스트

- [ ] 모든 인터랙티브 요소 hover/active/focus-visible/disabled 상태 정의
- [ ] 판정·사유 선택 시 낙관적 UI 갱신 + API 실패 시 토스트(한국어)
- [ ] 승인 버튼 disabled 사유를 버튼 아래 한 줄로 표기("미판정 2건 남음" 등)
- [ ] 승인→발송→done 이동 시 진행 상태 표시(버튼 스피너)
- [ ] 표(큐) 행 전체가 클릭 타깃, 키보드 포커스 가능
- [ ] 숫자는 tabular-nums, 시각은 `HH:MM` 고정폭
- [ ] 1440~1920 뷰포트에서 레이아웃 유지(max-width 1720 중앙 정렬), 1280에서도 깨지지 않게
- [ ] 스크린샷 찍었을 때 Figma 대비 위화감 없는 밀도·정렬(8px 그리드)
- [ ] 본문 텍스트 대비 4.5:1 이상(#a9a29a는 비활성 라벨 전용, 콘텐츠 금지)
- [ ] 한국어 줄바꿈이 어절 단위(keep-all)인지 육안 확인
- [ ] 빈 상태에 점선 테두리 금지
- [ ] 스크린샷 캡처 전 모든 전이 완료 상태 보장
- [ ] 화면당 채도 옐로 객체 1개 규칙 준수
